## 三、缺口審查

### 3.1 需求面：模型會輸出、但播不出來的 gloss

把 tslcorpus 平行語料 + 訓練/驗證/測試切分 + 合成句共 **84,144 個 gloss token** 丟進前端的 `resolve()` 邏輯（原鍵→去標記→複合詞表→數字逐位→大小寫折疊）：

## 七、把 fallback 的判定接上動作庫（同日補修）

用五句測試句實測時發現：今天補的詞**大多還用不到**。模型會把 `導盲犬`、`盲人`、`阿公`、
`停電`、`酪梨`、`氣炸鍋`、`連江縣`、`噩夢`、`河口` 全部輸出成 `指拼:X`，即使動作庫裡明明有影片。

原因在 `gloss_fallback.py`：它判斷「下游播不播得出來」用的是自己那份詞表
（`gloss_master.jsonl` 7,002 詞 ＋ 訓練集 ＋ 教育部詞表 = 合法詞 13,663／可播放詞 10,829），
**不是動作庫 `recordings/lexicon.json`**。兩邊一比，動作庫 17,078 條裡有 **4,184 條**
被判成表外、降級成指拼；而前端那 26 個字母動作根本還沒錄（`composer.js` 的指拼段就寫了），
標成指拼等於整個詞消失。

**修法**：`load_vocab()` 多接一個來源——動作庫的鍵，同時進「合法詞」與「可播放詞」
（有鍵就代表真的切得出那段動作）。找檔順序 `TSL_LEXICON_PATH` → 打包時的相對位置 →
主機預設位置，找不到就當作沒有（公開 repo 的使用者照樣能跑）；`TSL_USE_LEXICON_VOCAB=0`
可關掉做對照。含複合標記／斷詞符號的鍵（`擦+吊扇`、`雪／下雪`）不收，那不是單一個詞。

改完：合法詞 13,663 → **17,720**、可播放詞 10,829 → **17,022**。

| 驗證 | 結果 |
|---|---|
| 先前 8 句失敗句 | **8/8 全部變成整句播得出來**（連江縣、導盲犬、盲人、阿公、阿婆、停電、酪梨、秋葵、氣炸鍋、噩夢、河口） |
| 離線 fallback 評測（以動作庫為準的可播放率） | seen 82.65% → **97.87%**、paraphrase 81.61% → **97.70%**、unseen 86.59% → **97.77%** |
| 單元測試 | 新增 `tests/test_gloss_fallback.py` 4 條；repo 全部 7 條通過 |
| 服務 | 已重啟，健康檢查 200，五句推薦測試句全過 |

兩份 `gloss_fallback.py`（`0813/model_service/scripts/` 與 `tku-tsl-text-to-gloss/scripts/`）
內容本來就一樣，兩邊同步改，各留 `.bak-lexvocab` 備份。
